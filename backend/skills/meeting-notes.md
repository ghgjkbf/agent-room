# 会议纪要模板

用途：把一段群聊讨论整理成结构化纪要（Agent B 归档、项目复盘均可用）。

## 工作流

1. 收集要整理的聊天内容（消息文本 / 时间范围）。
2. 按下方模板输出；参会者即消息发送者，缺席主题不必展开。
3. 交付：写入工作区 `docs/minutes/<日期>-<主题>.md`，群里只发结论段。

## 模板

```
# 纪要 · <主题> · <日期>

## 参与者
<发送者列表>

## 讨论要点
- <要点 1>（提出者）
- <要点 2>（提出者）

## 达成结论
- <结论 1>

## 遗留事项
- [ ] <事项>（负责人 / 下一步）
```

## 要求

- 忠实记录，不添加讨论中没有的结论；有争议的观点并列呈现。
- 遗留事项必须带负责人或明确"待定"。
