# 工具定位：先问后查（Tool Location Confirm）

当任务需要调用某个外部程序或工具时，本技能强制「先问后查」：先做秒级快查，再向用户补充询问，绝不以全盘检索作为第一步。

## 硬性规则

1. 任务需要外部程序 X 时，**禁止**以全盘递归检索作为第一步
2. 第一步只允许秒级快查（见下方工具箱），通常在几秒内完成
3. 快查未找到 → 必须先用提问模板补充询问用户，不得擅自扫盘
4. 用户答复过的有效路径记入会话状态，本次任务内不重复询问

## 流程总览

```
任务需要程序 X
  ├─ ① 秒级快查（PATH / Get-Command / 注册表抽查）
  │     └─ ✓ 找到 → 校验后调用，继续任务
  ├─ ② 未找到 → 补充询问用户：「安装了吗？在哪？」
  │     └─ ✓ 用户给出路径 P → 校验存在且可执行 → 使用
  └─ ③ 用户答复「不存在」→ 提供三选项 A/B/C
        └─ 替代品仍未就绪 → 重回三选项（最多循环 2 轮）
```

## 提问模板

「任务需要用到 **{X}**。它是否已安装？安装路径是哪里？」

「这个任务涉及 **{仓库/项目/文件}**。它放在哪个目录？」

## 隐含触发场景（2026-08-27 教训回写）

工具定位需求常常**不直接出现在任务描述里**，而是藏在任务动词背后。以下场景即使没有出现「找工具」字样，也必须触发本技能：

| 任务样例 | 隐含需要定位 |
|---------|-------------|
| 「发布/提交/存储到 GitHub 仓库」 | 本地仓库位置 + git 或 GitHub Desktop |
| 「用 XX 软件打开/处理这个文件」 | 该软件的安装位置 |
| 「导出为 XX 格式」「压缩/转码」 | 对应处理程序（ffmpeg、magick 等） |
| 「打包/构建/出包」 | 构建工具链 |

真实教训：「帮忙存储在 GitHub 的仓库里」未触发本技能，Agent 盲探了错误目录，仓库实际位置靠用户事后告知。规则：**任务背后一旦依赖本机程序或仓库，先快查、再询问位置，不默认、不瞎猜。**

## 答复分流（提问后）

- **给了路径 P** → 校验路径存在且可执行；失败则报告具体原因并重询一次（防拼错路径直接报废）
- **说不准 / 忘了** → 升级快查：注册表卸载列表 + `Get-StartApps` + 常用安装目录抽查；仍未命中转三选项
- **不存在** → 当场给出三选项 A/B/C

## 三选项（用户答「不存在」时必须给出）

- **A · 终止该任务**：输出已完成部分与中止原因，安全收尾，不留半成品
- **B · 帮忙下载安装**：按安全边界流程，经用户同意来源与版本后再执行
- **C · 改用替代程序**：请用户提供替代品名称 Y，对 Y 重走①②步

## 循环限制

- 替代程序仍不可用 → 重回三选项，最多循环 **2 轮**
- 超过上限 → 明确列出阻塞原因，等待用户最终决策，不再自行尝试

## Windows 快查工具箱

| 对象类型 | 手段 |
|---------|------|
| CLI 工具 | `where.exe X`、`Get-Command X` |
| GUI 程序 | 注册表 Uninstall 键、`Get-StartApps` |
| 已装清单 | `winget list`（可用时） |

## 记忆挂钩

- **会话内**：确认过的有效路径立即缓存，本轮任务内不再重复询问
- **跨会话**：按记忆库规范写入 `tool_locations.md` 并同步 MEMORY.md 索引
- **复用时**：下次遇到同一程序跳过提问，仅保留一次秒级验证；目录已删除则重新询问

## 安全边界（优先级高于其他一切规则）

- 下载安装优先级：winget > choco > scoop > 官网直链；校验哈希/签名
- 需要管理员权限的操作必须先告知用户
- 不静默安装、不擅自修改 PATH
- 仅当用户明确授权「你去找」，才允许扩大检索范围（限白名单目录内）

## 批量询问

任务依赖 ≥2 个缺失工具时，合并为**一次**提问，列出完整清单与逐项状态，不连环打断用户。

## 与其他技能的边界

- 联网搜索现成方案/库 → 用 `search-first`
- 本技能只管**本机程序定位**与用户确认
- 与 `ponytail` 等效率类规则冲突时，安全规则优先于效率规则

## 验收用例

1. 任务要求调用 ffmpeg 但未安装 → 应触发提问而非全盘扫描
2. 回答「不知道」→ 应走升级快查而不是直接抛三选项
3. 第二次会话再次用到同一工具 → 应直接使用已存路径（含秒级验证）
