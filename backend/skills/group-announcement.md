# 群公告写作

用途：为群聊房间撰写一则公告（活动通知、规则变更、重要结论宣贯）。

## 工作流

1. 明确公告目的：通知什么、希望成员做什么、截止时间。
2. 按下方模板起草，控制在一屏以内。
3. 交付：写入工作区 `docs/announcements/<日期>-<主题>.md`，并在群里简述要点。

## 模板

```
【公告】<一句话主题>

事项：<要做什么>
时间：<何时 / 截止>
需要你做的：<每位成员需要采取的行动>
背景：<为什么要做，1-2 句>

如有疑问请 @发布人。
```

## 要求

- 标题即结论，正文不超过 200 字。
- 行动指令用祈使句，避免"可以考虑""建议大家"这类弱表述。
